## Deliberate boundaries

Neither tool is a default recommendation. Actual feature differences remain documented; neutral policy does not claim feature parity or completed comparative trials. The `.claude/skills` location remains a documented portable discovery location, not a vendor endorsement.

Development agents remain prohibited from TEST/PROD access. A delivered runtime agent may have separately assessed per-action authority; this is not permission for the engineering assistant to operate production.

The paper's "Copilot Code" branding/Frontier claims and Code Apps Git limitations were not independently established in this update. They are not imported as current product facts. Graduation guidance applies to any prototype; existing platform cards retain their dated support cautions.

New platform routes and sandbox/NIST references were checked on 8 November 2026. Existing adapter/vendor plugin checks remain dated 13 October 2026. Each guide names its consulted sources. Documentation review is not live tenant validation or customer approval.
