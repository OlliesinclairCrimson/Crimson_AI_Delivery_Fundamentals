# Release notes

## 0.1.0 - 13 October 2026

First tool-neutral reference derived from the supplied Claude Power Platform playbook.

- Separates fundamentals, shared client assets and replaceable tool adapters.
- Retains all 13 original workload areas and the seven-stage delivery lifecycle.
- Provides synchronized Claude Code / GitHub Copilot selectors with separate CLI and VS Code routes.
- Adds source-linked setup, per-client discovery workspace guidance, governance and pilot procedure.
- Makes AGENTS.md canonical and supplies six shared team skills, instruction bridges, evidence templates and a downloadable client starter.
- Uses public Learn-only MCP examples and explicit client-configuration blockers.
- Separates host deny rules from approval settings and identity/environment boundaries.
- Labels experimental Copilot Studio tooling and its different-harness successor accurately.
- Retires original Claude-specific videos from authoritative setup; written onboarding is complete.
- Adds pre-rendered/non-JavaScript routes, local fonts, print reading, automated checks and static packaging.

## Limits

No central live-tenant setup validation, policy enforcement test against vendor agents, comparative pilot, replacement recordings or actual hosting deployment is claimed. Those require approved environments and accountable owners. This is a publishable reference package, not an institutional policy approval or blanket permission to process client data.
